# learn-java-spring-in-action

这个目录专门用于学习《Spring 实战（第 6 版）》 / *Spring in Action, Sixth Edition*。

> `learn-java-spring-in-action/` 只是学习工作区，本身不是 Maven 工程。真正用于自己动手编写代码的 Maven 项目位于 `learn-spring-in-action-ning/`。

## 学习资料

- 中文翻译仓库：<https://github.com/LeonLi0102/spring-in-action-v6-translate>
- 原书官方配套源码：<https://github.com/habuma/spring-in-action-6-samples>
- 原书：*Spring in Action, Sixth Edition*，Manning

> 官方配套源码只用于对照学习；自己的练习内容统一放在 `learn-spring-in-action-ning/` 中。
