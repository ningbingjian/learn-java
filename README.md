# Java 进阶之书：零基础 → 资深架构师

> 一套「自用、但按可出版标准组织」的书级 Java 课程库。
> 结构：**7 部（Part）× 25 本主线书**。每本书内，主题都从零讲到资深（会用 → 原理 → 取舍 → 落地）；每部读完，用一个**从零独立规划**的收官项目验收。

## 从这里开始

- **先读总地图**：[CURRICULUM.md](CURRICULUM.md)——部 → 书 → 收官项目，一本书该有的深度一目了然。
- **写作/组织规范**：[docs/meta/writing-guide.md](docs/meta/writing-guide.md) + [章节模板](docs/_chapter-template.md)。
- **进度追踪**：[todo.md](todo.md)。

## 一句话结构

```
7 部（学习主线的大阶段）
 └─ 25 本主线书（每本 ≈ 一门可独立成书的专著，8–15 章）
     └─ 章（一章 ≈ 一次可写透 + 可跑 demo + 带自测）
每部读完 → projects/ 下的从零收官项目（通关验收）
全书学完 → Part VII 毕业设计
```

## 粒度标准（这本书为什么这么厚）

**凡能撑起一门专著的主题，就自成一本书**，配独立目录树、收官实验与篇幅预算；撑不满 8 章的主题才降级合并。
例如「Redis」不是一行「章」，而是一整本《Redis 原理与应用》（4 篇 15 章）。——这是「非常资深」应得的篇幅。

## 仓库怎么组织

```
CURRICULUM.md                ← 总地图（部→书→状态）
docs/meta/                   ← 写作规范 / 术语表 / 修订记录
docs/_chapter-template.md    ← 章正文模板
docs/part-0X-*/book-NN-*/    ← 每本书：README=书地图 + 正文 chNN-*.md（NN=部内阅读序号）
demos/book-NN-*/chNN-*/      ← 每章的 demo（真实可跑，自带 ./mvnw）
projects/part-0X-*/          ← 每部收官项目（从零）
docs/_archive/               ← 旧版「六卷」结构（留档）
```

## 环境基线（正文假定）

| 项 | 基线 |
|---|---|
| JDK | 21（LTS） |
| 构建 | Maven，经每个 demo 自带的 `./mvnw`（自举现代版） |
| 测试 | JUnit 5（自测即自检） |

## 标记约定

正文里的 `[待证]`（没把握）`[深潜]`（留给后续书）`[TODO-实验]`（缺实验/数字）`[?]`（未解问题）——详见写作规范。
