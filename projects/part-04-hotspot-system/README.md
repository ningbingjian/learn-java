# Part IV · 收官项目：高并发热点系统（Hotspot System）

> 所属：[Part IV 中间件与高并发](../../CURRICULUM.md#part-iv--中间件与高并发middleware-high-concurrency) · 状态 ⬜ 未动工

## 目标

从零做一个会「被挤爆」的热点业务（秒杀/抢券），用 Part IV 四本书（Redis/MQ/ES/分库）的武器撑住高并发，并证明**不超卖、可恢复**。

## 里程碑

- ① 商品/库存建模与 MySQL 底座
- ② Redis 预扣库存 + 缓存防穿透/击穿
- ③ MQ 削峰异步下单 + 幂等消费
- ④ 分布式锁守住「最后一单」边界 + 防重
- ⑤ XXL-Job/延迟任务超时关单（可选强化：分表）
- ⑥ 压测报告：极限 QPS、瓶颈定位、每层取舍

## 武器自限

单进程 + 中间件即可，**禁止拆微服务/服务治理**（那是 Part VI）；结论以压测为证。

## 验收（硬指标）

压测下**不超卖**；故障（杀 Redis/MQ/DB）后能恢复一致；报告说清每一环为应对什么而加。
