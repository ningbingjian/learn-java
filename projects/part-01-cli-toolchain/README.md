# Part I · 收官项目：命令行文档工具链（CLI Toolchain）

> 所属：[Part I 语言地基](../../CURRICULUM.md#part-i--语言地基language-foundation) · 状态 ⬜ 未动工

## 目标

从零做一套纯 JDK 的命令行文档处理工具链，把 Part I 四本书（环境/语言上下/数据结构算法）全部用上，对错**可客观对拍判定**。

## 里程碑（每个都有独立 SPEC + 自测判分器）

- ① [自写 JSON 解析器与格式化器](SPEC.md)——递归下降解析 → 树模型 → 格式化/压缩，错误带行列号
- ② CSV/INI 解析器（泛型/集合/IO 复用同一套解析思路）
- ③ Markdown→HTML 编译器（把文本解析成结构化，再渲染）
- ④ 文件统计与小型倒排索引 CLI（数据结构的收官实验整合进来）

## 武器自限

只许 JDK 标准库 + JUnit；界面为 CLI；禁止第三方库/数据库/网络。

## 验收（整体）

每里程碑判分器全绿 + 能处理各 SPEC 的「地狱样例」+ 命令可复现。
