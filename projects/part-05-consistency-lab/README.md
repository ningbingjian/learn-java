# Part V · 收官项目：一致性演练场（Consistency Lab）

> 所属：[Part V 分布式系统](../../CURRICULUM.md#part-v--分布式系统distributed-systems) · 状态 ⬜ 未动工

## 目标

从零搭一个「能看见最终一致如何达成」的演练场：注入故障 → 观察中间态 → 对账/补偿收敛。把 Part IV 的组件与 Part V 的理论粘成一个可实验的闭环。

## 里程碑

- ① 链路搭建：一个跨 Redis / MQ / DB 的「写-读」业务链路
- ② 故障注入台：断网/杀进程/乱序/重复投递（脚本可重复触发）
- ③ 幂等与对账：防重表 + 定时对账，把「脏数据」扫出来
- ④ 分布式锁/选主对照（Redis vs ZK）并压测差异
- ⑤ 实验报告：每种故障的「现象→原因→收敛」全过程记录

## 武器自限

允许 Docker 起中间件；故障与恢复必须可复现，禁止只描述不演示。

## 验收

对每种注入的故障，都能用 trace/日志/对账数据证明「最终一致收敛」，并给出适用边界。
