# Part II · 收官项目：性能观测实验台（Perf Lab）

> 所属：[Part II JVM·并发·网络](../../CURRICULUM.md#part-ii--jvm并发网络jvm-concurrency-network) · 状态 ⬜ 未动工

## 目标

从零做一个「能拿数字说话」的实验台，把 JVM 调优与并发对拍的能力沉淀成可复用脚本与报告模板。

## 里程碑

- ① 自写阻塞队列 + 线程池，与 JDK `ThreadPoolExecutor` 对拍（多负载压测）
- ② 复现 3 个并发陷阱（伪共享/锁竞争/死锁），各附「现象—原因—修复」
- ③ 三个 JVM 调优基准（高吞吐/低延迟/大堆），带 JFR/日志证据的报告
- ④ 输出一份可复现的压测报告模板（后续 Part 全部复用）

## 武器自限

纯 JDK + JMH/JFR/JCMD 等 JDK 自带工具；结论必须有数字。Netty 本书另做收官（不并入此实验台）。

## 验收

每个里程碑「一键跑 + 报告有对比、有结论」；报告不是截图堆，是能复现的命令与数字。
