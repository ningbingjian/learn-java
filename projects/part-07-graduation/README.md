# Part VII · 毕业设计（Graduation Capstone）

> 所属：[Part VII 架构师](../../CURRICULUM.md#part-vii--架构师architect) · 状态 ⬜ 未动工

## 目标

用 Part VII 三本书的方法，在**全新领域**从零交付一个完整系统，证明能力可迁移（不只是会做书里的项目）。

## 硬性要求（验收）

1. 需求分析：含明确澄清过的不确定点
2. 容量估算与成本取舍（有数字）
3. 关键决策全部写成 ADR（Part VII 收官练习整合进来）
4. 系统可重复部署 + 有压测数字
5. 一页「如果重做，我会改什么」复盘

## 选题约束

必须是前六部没做过的领域；组件按需自选，但每个选型要对得上 ADR 写法。

## 交付物

代码 + 全套架构文档（需求/容量/ADR/压测/监控）+ 答辩式复盘。
