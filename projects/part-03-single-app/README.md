# Part III · 收官项目：完整单体业务系统（Single App）

> 所属：[Part III 单体应用工程](../../CURRICULUM.md#part-iii--单体应用工程single-app-engineering) · 状态 ⬜ 未动工

## 目标

从零做一个「能上线、敢被测试、说得清设计」的完整单体 Web 系统，作为 Part IV 高并发改造的「被改造对象」。

## 里程碑

- ① 建模与数据库（迁移/索引）——MySQL 书收官整合进来
- ② 领域与业务接口（设计模式落地处）——设计模式书收官整合
- ③ Spring 装配 + 完整 REST API + 校验 + 统一异常
- ④ 安全加固（认证授权 + OWASP 防护）与全套测试
- ⑤ 设计取舍小结（≥5 条「为什么这么设计」）

## 武器自限

仍是单体：一个进程、一个库；**禁止中间件**（缓存/消息属于 Part IV）；允许 Docker 只跑数据库。

按 README 一键可跑 + 核心链路测试全绿 + 「哪里会先顶不住」的推演（留给 Part IV）。
