## 定位

把「协调」这一关切单独拎出：ZooKeeper/etcd 提供什么原语（顺序节点/监听/租约），它们与 Redis 锁的区别；以及分布式任务调度（XXL-Job）如何把「定时」变成可靠、可分片、可重试的工程能力。

## 收官实验

用 ZK/etcd 实现并压测一把「分布式锁 + 选主」，再用 XXL-Job 做一个可分片、可重试的批任务，故障演示恢复。

## 武器自限

允许 Docker 起 ZK/etcd/XXL-Job；锁与调度的「正确性」要有并发/故障证据。
