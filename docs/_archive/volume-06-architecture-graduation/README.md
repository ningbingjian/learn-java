## 本卷新增武器

从「解决问题」到「定义问题」：需求不清晰时怎么建模、方案多个时怎么选、选完怎么写 ADR 让未来可复盘。能在未知领域快速产出「设计 + 反方论证」。

## 武器自限（毕业设计不许做的事）

- **不许只用熟悉的套路**：必须挑一个前五卷没做过的领域（前五卷项目之外的域）。
- 交付物 = 代码 + **全套架构文档**（需求分析、容量估算、ADR、压测、监控）+ 一次「答辩式复盘」（自己当评委挑毛病）。
- 组件按需自选，但每个选型要能对得上卷五练出的 ADR 写法。

## 毕业设计（从零 · 独立规划）

**自选新域完整系统**。不指定域（避免剧透你选型），但验收有硬标准：

1. 有需求分析（含澄清过的不确定点）
2. 有容量估算与成本取舍
3. 关键决策有 ADR
4. 系统可重复部署 + 有压测数字
5. 有一页「如果重做，我会改什么」的复盘

它逼你用到：DDD 建模、系统设计方法、ADR/评审、以及前五卷全部武器（按需）。
