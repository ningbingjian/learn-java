## 本卷新增武器

工程化纪律（构建可复现、测试兜底、坏味道敏感）；SQL/事务/索引判断力；Spring 源码级理解；写出带安全面的完整单体 REST 服务。

## 武器自限（卷末项目不许用的东西）

- **禁止中间件**：不许用 Redis/MQ/ES/注册中心；数据只进数据库。
- **禁止微服务**：这是单体卷——一个进程、一个库。
- 允许：Spring Boot 全家、数据库、JUnit、容器（仅本地跑，不要求）。

## 卷末项目（从零 · 独立规划）

**完整单体业务系统**（三选一：博客 / 短链接 / 记账）。

- 交付：可运行的 Web 服务 + 数据模型 + 全套测试 + 一份「设计取舍」小结。
- 它逼你用到：数据库建模与事务、Spring 原理（AOP/事务边界）、安全防护、工程化测试。
- 验收 = 按 README 能一键跑起来 + 核心链路有测试 + 能说出 3 个「你为什么这么设计」。
- 备选说明：短链接在此是**本卷独立项目**，与之前的贯穿方案无关。
