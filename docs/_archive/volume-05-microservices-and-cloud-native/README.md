## 本卷新增武器

把单体演成可治理微服务的能力；SCA 生态选型与落地；容器与 K8s 上交付；全链路可观测与故障演练。能把「拆」和「演进」讲出理由（ADR），而不只是会用注解。

## 武器自限（卷末项目不许用的东西）

- **禁止自己手搓治理逻辑**：注册/配置/限流/事务一律走本卷生态组件，不许另造轮子。
- 交付必须是**能重复部署**的（Docker/K8s 编排 + CI 脚本），不是「在我电脑上能跑」。

## 卷末项目（从零 · 独立规划）

**从零微服务系统**（SCA 全家桶 + 容器化 + CI + 可观测 + 一次故障演练）。

- 拆 3–4 个服务，Nacos 注册配置、Gateway 入口、Sentinel 保护、RocketMQ 解耦、Seata（确有必要处），Docker/K8s 部署，SkyWalking 链路。
- 「单体演进史」作为 **ADR 文档 + 可选演练**（把卷三单体演进到这里，用于讲清楚每个拆分决策），不强求代码承接。
- 验收 = 从零按文档能一键部署整套 + 故障演练有复盘记录。
