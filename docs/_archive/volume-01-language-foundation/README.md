## 本卷新增武器（学完你会拥有的能力）

纯 JDK 命令行编程：面向对象建模、集合与泛型、异常边界、IO 读写、lambda/Stream 基础、看懂一次 JVM 崩溃/GC 日志的基本概念，并**会用 JUnit 给自己的代码写自测**（从 ch00 就养成）。

## 武器自限（卷末项目不许用下面的东西）

- 禁止任何第三方框架（Spring 等）、禁止数据库/中间件/网络库。只用 JDK 标准库 + JUnit。
- 界面只能是命令行（CLI），最多文本文件持久化。

## 卷末项目（从零 · 独立规划）

**自写 JSON 解析器与格式化器**（纯标准库 CLI）。

- 输入：一个 JSON 字符串/文件；输出：解析后的对象模型、格式化/压缩后的文本、友好的语法错误报告。
- 项目规格书（需求/验收/自测判分器）：原 `projects/volume-01-json-parser/` 已并入现行 Part I 收官项目，SPEC 见 [projects/part-01-cli-toolchain/SPEC.md](../../../projects/part-01-cli-toolchain/SPEC.md)。
- 备选选题：Markdown→HTML 编译器；命令行记账本。
- 它能逼你用到：集合/泛型（递归下降后的树模型）、异常边界（错误报告）、IO（读文件）、函数式（遍历/格式化）。
