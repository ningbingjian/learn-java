## 本卷新增武器

缓存/消息/检索/分片/调度的选型判断与排障力；分布式锁、幂等、分布式事务的「什么时候用哪种」矩阵；高并发场景的拆解能力。能对卷三单体做一次「哪里会先挂」的推演。

## 武器自限（卷末项目不许用的东西）

- **禁止微服务/服务治理**：仍是单进程应用 + 中间件，不拆服务、不用注册中心做 RPC（注册中心原理本章只读，动手在卷五）。
- 中间件**允许**：Redis、RocketMQ、XXL-Job、（可选强化：ShardingSphere 分表）。
- 结论必须有压测与调优数字。

## 卷末项目（从零 · 独立规划）

**限时秒杀系统**（单进程 + 中间件）。

- Redis 预扣库存 → MQ 削峰异步下单 → 分布式锁保证不超卖 → 幂等防重 → XXL-Job 超时关单。
- 交付：系统 + 一份「压测报告」：极限 QPS、瓶颈在哪、怎么调的。
- 验收 = 压测下**不超卖**（这是硬指标）+ 报告能说清每个瓶颈的取舍。

## 前置 / 出口

- 前置：卷三（需要那套单体与数据库底子）。
- 进入卷五的条件：秒杀不超卖 + 你能说清「哪一环是为了应对什么问题而加的」。
