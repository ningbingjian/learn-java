## 收官实验

对给定的新需求（或自选）独立完成一次完整设计：容量估算 → 架构图 → 关键决策与反方论证，产出设计文档。

## 武器自限

设计以「可量化、可辩驳」为标准；每个选型要有反方或失败场景。
