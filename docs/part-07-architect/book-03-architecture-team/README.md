## 定位

架构师一半是技术一半是「让技术决策可沉淀、可协作」的工程：ADR 怎么写、评审怎么开、技术债怎么管、故障怎么复盘。本卷把方法论固化成自己的习惯。

## 收官实验

复盘整本书里你做过的 3 个大决策，用 ADR 标准重写并互评；为毕业设计产出全套 ADR。

## 武器自限

以「写得清、能辩驳、可复查」为验收，不追求模板套话。
