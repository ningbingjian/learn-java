# 《MySQL 数据库核心》

> Part III · 第 3/5 本 · 状态 🟡（目录已立）

## 定位

从建模与 SQL，到 InnoDB 引擎、索引与执行计划、事务与锁，再到主从高可用与备份。目标：写得出高效 SQL、看得懂执行计划、说得清事务与锁、能处理线上慢查询。

## 前置

Part I/II（本卷不依赖 Spring，可与 Spring 两卷并行）。

## 章目录

- ch01 · 关系模型与表设计（范式与反范式）
- ch02 · SQL 精进：连接/聚合/子查询/窗口函数
- ch03 · InnoDB 架构（页/缓冲池/redo undo）
- ch04 · 索引原理：B+ 树与联合索引最左前缀
- ch05 · 执行计划与优化器（EXPLAIN 实战）
- ch06 · 慢查询治理（三个线上案例）
- ch07 · 事务：ACID 与隔离级别（读已提交/可重复读差异）
- ch08 · 锁：行锁/间隙锁/意向锁与死锁
- ch09 · MVCC 与一致性读
- ch10 · 崩溃恢复与 binlog（redo/undo/binlog 协作）
- ch11 · 主从复制与高可用（异步/半同步/组复制直觉）
- ch12 · 备份与恢复、容量与压测

- ch14 · 数据库设计评审清单

## 收官实验

造一份「合理规模」的数据（≥百万行），对 5 类慢查询做 EXPLAIN→建索引→复测，产出一份可复现的优化报告。

## 武器自限

允许本机 Docker 跑 MySQL 做实验；调优结论必须有执行计划或压测前后对比。
