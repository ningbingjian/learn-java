# 《设计模式与重构》

> Part III · 第 2/5 本 · 状态 🟡（目录已立）

## 定位

在**真实代码**里学模式与重构：模式是「何时该用」的决策，不是背图。每个模式都去 JDK/Spring 里找到它活着的例子，再配一个「该用而没用 / 不该用而滥用」的反例。

## 前置

[《Java 语言核心（上）》](../../part-01-language-foundation/book-02-java-core-basics/README.md) 面向对象基础。

## 收官实验

把一段「面条式业务代码」经两轮重构改造成模式清晰的版本，每步都有测试兜底，附重构记录。

## 武器自限

以 JDK + 测试为工具；讲模式必须带「反模式/滥用」的对照。
