# 《Java 语言核心（上）：基础与面向对象》

> Part I · 第 2/4 本 · 状态 🟡（目录已立）

## 定位

零语法基础的正式起点：变量与类型、控制流、方法与数组，然后是 Java 的灵魂——面向对象（封装/继承/多态/接口）。每一章都要「会写 + 会解释为什么这么设计」。

## 前置

[《开发环境与工具链》](../book-01-env-toolchain/README.md)。

## 章目录

- ch01 · 变量与基本类型（值语义/范围/装箱直觉预埋）
- ch02 · 运算符与控制流（含短路、三元、switch 演进）
- ch03 · 方法与参数传递（值传递的真相、重载）
- ch04 · 数组（与 for-each 原理）
- ch05 · 面向对象总览与封装（类/字段/方法/构造）
- ch06 · 继承与多态（方法分派、向上转型）
- ch07 · 接口与抽象类（契约与实现分离）
- ch08 · 内部类与匿名类（闭包直觉）
- ch09 · 枚举与 `record`（值对象初识）
- ch10 · 异常处理机制（try-with-resources、最佳实践起点）
- ch11 · 调试与排错基本功（断点/栈/日志）

## 收官实验

纯 JDK 写一个带状态的命令行小游戏（如猜词/数独 CLI），覆盖本卷 OOP 大部分机制，并配 3 个 JUnit 自测。

## 武器自限

只许 JDK 标准库 + JUnit；不引入任何集合高级 API 之外的技巧（下本书才讲集合源码）。
