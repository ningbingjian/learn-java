# 《开发环境与工具链》

> Part I · 第 1/4 本 · 状态 🟡（目录已立）
> 内容与规范见 [writing-guide](../../meta/writing-guide.md)

## 定位

从零把「电脑上写 Java 的最小闭环」跑通：终端、Git、JDK、构建工具、编辑器，直到能一键运行一个**带自测**的工程。本卷唯一不讲语法的书，但所有后续书的根基。

## 前置

无。任何人从这里开始。

## 章目录

- ch01 · 终端与 Shell——把命令行用起来
- ch02 · Git 版本控制：从提交到分支协作
- ch03 · JDK 安装与多版本管理（jenv/sdkman/原生安装）
- ch04 · Maven 原理与依赖管理（坐标/生命周期/仓库）
- ch05 · Gradle 对照（何时该换）
- ch06 · 编辑器/IDE 工作流（快捷操作、调试器、重构键位）
- ch07 · 从零一键跑通「带测试的 Java 工程」（对接现成 demo）

## 收官实验

写一个可复用脚本：新机器从空目录一条命令 → 拉代码 → 编译 → 跑通测试。验收 = 在干净目录能复现。

## 武器自限

本卷不写业务逻辑；能跑通最小闭环即达标。
