# 07. Spring Cloud、Spring Cloud Alibaba 与 Dubbo 微服务生态【主线】

[总导航](00-学习路线总导航.md) · [上一份：06-中间件、分布式原理与数据一致性](06-中间件、分布式原理与数据一致性.md) · [下一份：08-生产交付、云原生与可靠性工程](08-生产交付、云原生与可靠性工程.md) · [参考资料](15-参考资料.md)

本阶段在分布式原理之后，系统展开 Spring Cloud、Spring Cloud Alibaba 与 Apache Dubbo。第 6 阶段讨论机制和取舍，本阶段讨论框架接入、治理、诊断与生态协作。

Spring Cloud Alibaba 与 Apache Dubbo 各自演进，可与 Spring Boot、注册配置中心和其他组件组合。具体依赖按所选版本的兼容关系确定。参见 [Spring Cloud Alibaba 官方入口](https://sca.aliyun.com/en/) 和 [Apache Dubbo 官方核心能力](https://dubbo.apache.org/en/overview/what/core-features/)。

OpenFeign 保留为重要学习内容，同时包含 HTTP Service Clients 的迁移专题；Spring 官方将 OpenFeign 定位为功能完整状态，并建议考虑后者。[官方说明](https://docs.spring.io/spring-cloud-openfeign/reference/index.html)
