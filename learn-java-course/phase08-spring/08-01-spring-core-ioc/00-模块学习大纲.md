本文件规划本模块从零基础到源码与工程实践的完整课程。课程正文、可运行示例和测试按课交付；[第001课](001-why-spring-container/README.md)、[第002课](002-ioc-di-object-assembly/README.md)、[第003课](003-runnable-debuggable-spring/README.md)、[第004课](004-java-config-object-assembly/README.md)与[第005课](005-maintainable-container-tests/README.md)已编写，其余课程待展开。下列尚未交付的项目与实验仍是学习规划，不代表已经运行验证。

## 1. 学习目标与范围

完成本模块后，应能够独立配置与测试 Spring 容器，解释对象从定义到销毁的执行路径，定位装配和生命周期问题，并设计可维护的容器扩展。源码学习的成果包括带运行证据的调用路径、关键对象状态、分支选择及设计取舍，不能以背诵类名代替。

本模块覆盖 spring-core、spring-beans、spring-context、spring-expression，以及支撑学习所需的 spring-test。代理只讲与容器对象包装、配置增强、作用域和早期引用相关的接点；切点匹配、拦截链和织入细节由 08-02 承接。事务资源协调、MVC 请求处理、Boot 自动配置和 Modulith 分别由对应模块承接。Web 作用域和 LoadTimeWeaver 在相关机制处建立衔接，不在此扩展成 Web 或织入课程。

前置能力：Java 类、接口、构造器、异常、集合，Maven 基础与 IDE 断点。泛型、反射、注解和并发知识随使用补齐；源码篇开始前应能理解继承层次、回调和基础缓存结构。第一课从普通 Java 对象协作开始，不要求先学 Boot、数据库或微服务。

## 2. 版本、工程与学习方式

- 应用示例基线选用 JDK 21、Spring Framework 7.0.9 和 Maven；源码对照固定为官方 v7.0.9 标签。第001—005课已验证 JDK 21 与 Maven 聚合构建，JUnit、Spring BOM 和插件版本集中在父 POM 中；第003课已引入并验证 Spring 依赖、同版本源码与容器运行。
- Spring 本体源码工程使用其自带 Gradle Wrapper，并遵循该标签的工具链要求；应用示例的 JDK 选择不能直接推定为框架源码构建要求。
- 运行依赖、sources 包和源码标签必须一致。版本演进篇另选固定 6.2.x 标签进行对照，分别记录差异。
- 以订单服务、库存适配和通知组件作为连续业务案例。前期通过内存实现运行，后续增加配置切换、扩展、生命周期与故障场景。
- 后续源码组织为本模块下的 Maven 聚合工程，按课程建立子模块并统一管理依赖。文档与示例相互定位，当前已建立聚合工程与第001—005课子模块，后续随课程增加可运行的子模块。
- 应用篇建立可观察行为，源码篇回到同一行为解释内部实现。第一轮可学至第07篇完成业务应用；第二轮进入源码，随后完成扩展、AOT 与综合项目。

## 4. 源码学习的执行路径与观察对象

下表是源码篇的定位索引，不是所有场景都会原样经过的单一调用栈。后续课程需在相应作用域、配置方式与容器状态下验证分支。

| 路径 | 主要入口 | 应追踪的信息 |
| --- | --- | --- |
| 容器启动 | AnnotationConfigApplicationContext → AbstractApplicationContext.refresh | 上下文状态、工厂对象、后处理器与监听器 |
| 配置注册 | ConfigurationClassPostProcessor → ConfigurationClassParser → ConfigurationClassBeanDefinitionReader | 配置模型、导入关系、条件结果与 BeanDefinition |
| 扫描注册 | ClassPathBeanDefinitionScanner → BeanDefinitionRegistry | 资源、元数据、过滤结果与命名冲突 |
| 查找与创建 | AbstractBeanFactory.doGetBean → AbstractAutowireCapableBeanFactory.createBean / doCreateBean | 合并定义、作用域、已存在对象与正在创建状态 |
| 依赖解析 | populateBean → 注入处理器 → DefaultListableBeanFactory.resolveDependency | 注入点、候选集合、限定信息与最终引用 |
| 初始化与包装 | initializeBean → 前后处理器及初始化回调 | 原始实例、回调顺序、替代对象与暴露引用 |
| 早期引用 | DefaultSingletonBeanRegistry 与 getEarlyBeanReference | 创建状态、早期引用来源、最终对象一致性 |
| 产品对象 | getObjectForBeanInstance → FactoryBeanRegistrySupport | 工厂与产品、类型信息、缓存与资源责任 |
| 关闭清理 | doClose → 生命周期处理与单例销毁 | 依赖关系、停止回调、销毁顺序与资源状态 |
