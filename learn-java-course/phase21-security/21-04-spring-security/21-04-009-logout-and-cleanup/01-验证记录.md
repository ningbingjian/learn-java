## 后端真实HTTP

本课`mvn clean verify`共66项通过，无失败、错误或跳过。继承第八课58项：请求边界27、密码存储5、CSRF9、表单登录9、当前用户8；新增LogoutHttpTests 8项。

新增测试分别验证：JSON/HTML请求统一204且空正文、无Location与no-store；JSESSIONID过期；缺令牌403后原会话仍可访问并能修复；错误令牌不退出；GET返回确认页而/me和/hello仍200；重放原Cookie时/me与/hello401、原CSRF探针403；新匿名令牌可提交探针但无认证、再次登录成功；匿名会话带新令牌可重复手动退出；另一个独立会话保持原身份。

本机容器实际发送Expires形式的过期Cookie，断言使用解析后的过期语义与路径，而不是强制要求Max-Age文本。Cookie删除之外，还使用原标识重新发真实请求证明服务端已拒绝旧认证。

固定版本源码核对LogoutFilter、LogoutConfigurer、SecurityContextLogoutHandler和CsrfLogoutHandler。新增LOGOUT_HANDLER_REACHED只证明进入退出处理链；清理结果由后续真实请求证明。测试使用隔离密码，普通启动仍需实验环境变量。
