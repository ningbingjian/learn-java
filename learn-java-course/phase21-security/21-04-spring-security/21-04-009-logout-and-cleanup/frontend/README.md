# 第009课独立前端：安全退出与页面收尾

[课程正文](../README.md) · [验证记录](../01-验证记录.md)

本项目接通带CSRF的POST `/api/logout`。后端204确认退出后清理身份与旧令牌，再取得匿名CSRF令牌；退出被拒绝或响应不明时，重新查询/me核对实际会话，不自动重发POST。

## 启动

按正文准备JDK21、Maven3.9.9与三个`LESSON_*_PASSWORD`环境变量，在本课后端目录执行`mvn spring-boot:run`，默认127.0.0.1:8080。普通启动没有可用的默认密码。

另开终端进入本目录，使用Node22.15.0和npm10.9.2：

```bash
npm ci
npm run dev
```

浏览器打开`http://127.0.0.1:5173`。Vite8.2.2移除`/api`前缀并代理到后端。首次学习从[正文](../README.md)复制第八课建立独立跟写工程，本目录为完成版快照。

## 操作

1. 登录member，当前身份和会话访问均成功。
2. 点击“退出当前会话”，请求为带Cookie和CSRF头的POST，204没有JSON正文。身份、两处密码输入及旧登录/会话成功提示清理。
3. 等待新匿名令牌就绪；会话访问401，正常公开探针200，说明CSRF准备与认证不同。
4. 重新输入密码登录成功；退出没有删除用户或使密码失效。
5. 离线时退出显示结果未知，不能宣称成功；恢复网络先查询身份，再取得令牌、显式决定是否退出。

`session-client.js`在共享队列中执行退出和令牌恢复，只有未知/拒绝时额外查询/me。204之后令牌GET失败仍保留已退出结论。`logout.js`负责输入和历史提示清理；`current-user.js`的未登录文案不再固定写401，因为204也能确认退出。

原匿名/Basic实验区仍保留独立请求条件与历史结果，不作为当前身份来源。不会清空其他应用数据或批量删除localStorage；也不提供跨标签页实时同步或全设备退出。

## 构建与测试

在本目录执行，确保Maven使用JDK21：

```bash
npm run build
npx playwright install chromium
npm run test:e2e
```

可用`MAVEN_CMD=/绝对路径/mvn npm run test:e2e`指定Maven。脚本先运行66项后端测试并构建，再启动真实Java、Vite和Chromium，执行28项浏览器测试。

新增测试覆盖真实退出与旧Cookie重放、缺令牌403及修复、204后仅CSRF GET失败、真实退出响应丢弃、退出后刷新和窄屏键盘、离线退出未到后端。响应丢弃实验先实际执行POST，再丢弃浏览器可见响应；不会用假的204替代真实退出。

`.e2e-work/before-login/`仍是继承的默认表单响应对照，保留/me，但没有本课显式退出配置；退出场景均针对完成版后端。trace关闭，截图只记录已清空输入的页面，不发布真实密码、Cookie、令牌或Network详情。本课仍是同源开发代理，不代表已验证跨源部署。
