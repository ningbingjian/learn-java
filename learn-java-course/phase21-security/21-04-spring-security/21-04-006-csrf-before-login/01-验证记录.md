## 后端证据

保留第五课32项用户、密码存储、请求匹配、认证响应及框架登录回归。新增`CsrfHttpTests`使用实际端口与独立CookieManager，每个会话有自己的Cookie容器，不使用模拟认证，合法令牌全部经GET接口取得，错误对照才使用故意无效值：

1. 匿名GET `/csrf`200，响应包含默认头名X-CSRF-TOKEN、参数名_csrf和非空令牌；no-store、HttpOnly JSESSIONID与无Basic挑战符合预期。
2. 同一会话与令牌POST200，返回固定探针消息。
3. permitAll探针仍拒绝缺失与错误令牌，均403。
4. 有令牌而无Cookie仍403。
5. B会话带A会话令牌403。
6. 同一会话两次取得的文本不同，但两个掩码表示均可POST200，不把文本变化当成自动失效。
7. 会话与CSRF令牌不能认证用户，GET `/hello`仍401。
8. 正确Basic不能替代POST令牌，无令牌403。
9. 借框架POST `/logout`使会话失效，旧令牌拒绝，重新取得后200。这只是失效回归，完整退出教学在第009课。

第9项初次预期跳转302，而本配置对JSON请求实际返回204。核对实际响应后固定为204，并继续验证旧令牌确实失效以及新令牌修复成功；没有把退出成功状态随意放宽成多个可能值。该步骤不用于提前声称已实现前端退出。

固定标签核对了CsrfFilter的延迟加载、方法判断和拒绝分支，HttpSessionCsrfTokenRepository的会话读写，以及XorCsrfTokenRequestAttributeHandler的响应掩码与提交解析。正文限定当前默认组合，没有混用CookieCsrfTokenRepository。

## 浏览器证据

前课匿名/Basic、参数与认证错误、默认登录页、真实后端停止/恢复、离线恢复、异常格式降级、方法/路径边界和窄屏测试继续运行。隔离对照改为移除CSRF入口：初始化失败，提交禁用；完成版初始化就绪。

新增三项联合场景：

- 同会话合法请求200，浏览器实际携带Cookie和X-CSRF-TOKEN且不带Authorization；缺失/错误/不带Cookie三种真实请求均403，后端探针计数不增加；恢复正常请求200，计数再次增加，令牌不出现在页面或持久存储。
- 清除Cookie后使用缓存令牌得到403，正常提交禁用；重新获取不自动POST，再手动提交200。
- 离线重新初始化失败、提交禁用；恢复网络重新获取成功；390像素以Enter提交200且无横向溢出。

CSRF验证全部使用真实服务，没有注入假令牌成功响应。只有继承的“异常格式”用例模拟响应，用于前端降级。进程采用空闲端口并在结束后关闭；关闭网络追踪留存，令牌及Cookie不展示在截图与观察区。

## 适用范围

探针不修改业务数据，匿名许可仅用于隔离CSRF条件；未来业务写接口仍需认证和授权。没有禁用CSRF，没有新增统一403业务契约。默认错误体字段不作为稳定API承诺。

未验证浏览器直连跨源CORS、生产部署、攻击页面演示、XSS防御或全部认证生命周期；正式独立前端登录在第007课。前五课本次仅重跑后端回归，不把历史浏览器结果冒充本次验证。
