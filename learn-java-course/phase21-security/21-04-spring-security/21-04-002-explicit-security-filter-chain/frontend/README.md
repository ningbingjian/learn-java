# 第002课独立前端：公开与受保护请求观察台

[第二课正文](../README.md) · [验证记录](../01-验证记录.md) · [模块入口](../../README.md) · [版本基线](../../01-版本基线.md)

本课沿用原生HTML、JavaScript与Vite，增加公开信息按钮，与受保护接口按钮共用结果区。页面显示本次路径、真实HTTP状态、响应来源和响应内容；不包含登录表单、身份存储或角色菜单。

## 启动完成版

先在本课目录（本目录的上一级）使用JDK21、Maven3.9.9执行 `mvn spring-boot:run`，默认后端为 `127.0.0.1:8080`。另开终端在本目录执行：

```bash
npm ci
npm run dev
```

基线为Node.js22.15.0、npm10.9.2、Vite8.2.2。打开 `http://127.0.0.1:5173`，点击“访问公开信息”应得到200；点击“访问受保护接口”应得到401。本课始终保留安全依赖，只有按正文新增安全链以后公开GET才匿名可用。

| 操作 | 浏览器请求 | 开发代理转发到后端 |
| --- | --- | --- |
| 访问公开信息 | GET /api/public/info | GET /public/info |
| 访问受保护接口 | GET /api/hello | GET /hello |

两个按钮都设置 `credentials: 'omit'`且不设置Authorization，使比较条件一致。后端规则写代理重写后的路径。开发代理只在连接失败时生成带 `X-Lesson-Proxy-Error`标记的502，后端401及认证挑战原样转发。浏览器没有直连8080，本课不构成CORS验证。

后端改用8081时，在本目录执行 `LESSON_BACKEND_URL=http://127.0.0.1:8081 npm run dev`并重启代理；前端5173被占用时可执行 `npm run dev -- --port 5174`并访问对应地址。不要同时启动第一课与第二课占用相同端口。

## 页面交互与故障恢复

按钮通过固定 `data-path`选择请求目标。请求开始时显示本次路径，清空旧响应并禁用两个按钮；结束后恢复按钮及各自文字，避免共用结果区产生请求竞争。响应采用 `textContent`展示，不执行HTML。

正常完成版：公开200并增加 `PUBLIC_INFO_HANDLER_REACHED`，匿名受保护401且没有新增 `HELLO_HANDLER_REACHED`。默认链对照版中，即使已有公开Controller，匿名公开请求仍为401。

保持前端运行、实际停止后端时，两按钮都显示代理502；重启正确后端后分别恢复200和401。页面加载后浏览器离线时显示“未取得完整响应”，不猜测认证结果；恢复网络可原页重试。两种故障都不应显示成“未登录”。

## 构建与联合验证

```bash
npm run build
npx playwright install chromium
npm run test:e2e
```

普通页面学习只需开发服务，自动化验证才需要安装匹配的Chromium。`build`只生成 `dist/`静态文件，不包含Java服务或Vite开发代理，部署API入口需另行安排。

联合测试使用Java21、Maven3.9.9、Playwright Test1.63.0；可通过 `JAVA_HOME`和 `MAVEN_CMD`指定本机工具路径。脚本先在完成版运行11项真实HTTP测试并打包，再在 `.e2e-work/before-chain`复制主源码，仅移除 `SecurityConfig.java`，构建保留安全依赖与公开Controller的默认链对照版；它不会删除安全依赖来制造公开200。

随后启动真实Java服务、Vite与Chromium，用空闲端口完成6项浏览器测试：默认链公开401、显式链公开200、同页切换受保护401、真实后端停止/恢复、浏览器离线/恢复、390像素窄屏与键盘。测试检查请求不携带Cookie/Authorization、安全响应头及业务方法日志，结束后关闭服务。

构建日志在 `.e2e-work/`，截图与失败追踪在 `test-results/`，均不提交。正文写错代理前缀的故障实验还通过独立跟写工程实际构建、运行、修复；详细范围见[验证记录](../01-验证记录.md)。
