把页面结果与后端执行对应起来

  1. 看状态：200是本次成功；401表示本次请求需要认证。
  2. 看请求：在浏览器 Network 中找到 /api/public/info 或 /api/hello，检查状态与请求头。
  3. 看日志：公开操作是否新增 PUBLIC_INFO_HANDLER_REACHED，匿名受保护操作是否没有新增 HELLO_HANDLER_REACHED？
