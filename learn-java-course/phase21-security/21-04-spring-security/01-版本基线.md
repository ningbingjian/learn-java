原有后端版本已通过第一课的 Maven 依赖树核对；第003课新增核对Jackson databind/core 3.1.5，未改变父POM基线。声明由 [Boot 4.0.8 BOM](https://repo.maven.apache.org/maven2/org/springframework/boot/spring-boot-dependencies/4.0.8/spring-boot-dependencies-4.0.8.pom)提供，构建插件由 [Boot 4.0.8父POM](https://repo.maven.apache.org/maven2/org/springframework/boot/spring-boot-starter-parent/4.0.8/spring-boot-starter-parent-4.0.8.pom)管理。

本模块采用 Boot 4.0.8 的 `spring-boot-starter-webmvc`、`spring-boot-starter-security` 和 `spring-boot-starter-test`。第001—004课普通启动不设置用户名或密码属性，观察默认用户与随机生成密码；第005课开始显式提供用户服务，通过三个本机环境变量提供实验密码，详见当课正文。测试用例只覆盖测试上下文中的密码，以保证失败和成功请求可重复；该密码不是运行环境的默认密码。

前端依赖在第一课 `frontend/package.json` 中使用准确版本，传递依赖固定在 `package-lock.json`。Vite8.2.2要求Node `^20.19.0 || >=22.12.0`，本课程使用22.15.0；版本信息已核对[npm发布元数据](https://registry.npmjs.org/vite/8.2.2)。前端无需先学习组件框架，使用原生HTML、CSS、JavaScript与浏览器fetch。

## 环境确认与依赖核对

在本模块目录执行：

```bash
java -version
mvn -v
mvn clean verify
mvn -pl 21-04-001-hello-spring-security dependency:tree '-Dincludes=org.springframework:*,org.springframework.security:*,org.junit.jupiter:*,org.apache.tomcat.embed:*'
```

`java -version` 与 `mvn -v` 都应显示 Java 21；两者不一致时，先修正本机 Maven 使用的 JDK。依赖过滤参数加引号，以避免 shell 把星号当成文件匹配。

构建会从 Maven 仓库解析依赖，需要首次下载所需的网络访问。第一课运行只使用本机端口，不依赖数据库、Redis、Docker 或外部身份服务。8080 被占用时可在单课目录使用 `mvn spring-boot:run -Dspring-boot.run.arguments=--server.port=8081`，同时替换终端请求中的端口，并在 `frontend/` 用 `LESSON_BACKEND_URL=http://127.0.0.1:8081 npm run dev`重启开发代理。

在第一课 `frontend/` 目录执行：

```bash
node --version
npm --version
npm ci
npm run build
npx playwright install chromium
npm run test:e2e
```

后两条仅用于浏览器自动化验证；普通学习执行 `npm run dev`即可启动前端。联合验证要同时满足Java与Node环境。首次npm安装和测试浏览器下载需要网络，后续页面调用的业务接口均在本机。前端5173，后端8080；浏览器通过开发代理同源请求API，本课不把代理转发视作完成跨域认证配置。[Vite代理文档](https://vite.dev/config/server-options#server-proxy)说明其开发阶段的作用。

## 文档、源码与升级规则

参考说明使用 [Spring Security 7.0 文档](https://docs.spring.io/spring-security/reference/7.0/index.html)，该分支可能继续更新补丁版本；涉及具体实现时以 [Security 7.0.7标签](https://github.com/spring-projects/spring-security/tree/7.0.7)、[Boot v4.0.8标签](https://github.com/spring-projects/spring-boot/tree/v4.0.8)和本地解析的依赖为准。

在 IDE 中导入模块父 POM，并下载 Maven Sources。需要批量取得源码时，在本模块目录执行 `mvn -pl 21-04-001-hello-spring-security dependency:sources`。框架类必须打开依赖对应的 Sources，不能用另一版本网上的方法位置替代。

后续课程优先继承当前基线。升级时一起修改父 POM，核对实际依赖树，重新运行受影响章节的正常、拒绝与故障修复场景，并更新源码链接和验证记录。前端升级同步更新package.json及锁文件，重新验证构建、真实浏览器状态、代理边界与故障恢复。需要讲迁移差异时单独说明旧基线与新基线，不静默替换第一课已验证的版本。

本次验证环境为 macOS arm64；Java/Maven命令不依赖该架构。正文目录创建与复制命令采用 macOS/Linux shell，Windows 学习者可在 Git Bash 中执行；本次未单独验证 Windows、其他 JDK 或其他依赖版本。

## 后续课程引入环境的规则

逐课大纲中的数据库、身份服务、LDAP、证书及原生镜像均为计划中的实验环境，尚未在本模块落地或验证。首次引入时，正文必须列出新增依赖、启动和重置方法、端口及验证条件：受Boot管理的库记录实际解析版本；未受管理的库固定准确版本；容器使用固定标签并记录镜像摘要，不能使用浮动的 `latest`。

外部身份实验提供可重复导入的本地配置和测试账号，不依赖学习者的个人线上账户。源码与迁移实验分别注明工程来源及使用的基线；候选升级放在隔离实验中，验证完成后再更新正式基线，不能将“计划支持”写成“已经实测”。
