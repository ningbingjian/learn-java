## 固定的教学环境

本模块固定以下组合，版本用于复现实验，不表示自动追随最新发布。实测日期：2026-09-07。

| 项目 | 基线 | 管理位置与作用 |
| --- | --- | --- |
| JDK | 21；本次实测 OpenJDK 21.0.9 | 父 POM 的 `java.version=21`，统一编译目标 |
| Maven | 3.9.9 | 本次构建工具；先以 `mvn -v` 确认实际使用的 Java |
| Spring Boot | 4.0.8 | 父 POM 继承 `spring-boot-starter-parent`，统一依赖与插件管理 |
| Spring Security | 7.0.7 | Boot BOM 管理；不在子课单独覆盖 |
| Spring Framework | 7.0.9 | Boot BOM 管理，与当前 IoC 模块版本一致 |
| Tomcat | 11.0.24 | Boot 管理的嵌入式 Servlet 容器 |
| JUnit Jupiter | 6.0.3 | Boot 测试依赖管理，不套用 IoC 模块的 JUnit 版本 |

版本已通过第一课的 Maven 依赖树核对。声明由 [Boot 4.0.8 BOM](https://repo.maven.apache.org/maven2/org/springframework/boot/spring-boot-dependencies/4.0.8/spring-boot-dependencies-4.0.8.pom)提供，构建插件由 [Boot 4.0.8父POM](https://repo.maven.apache.org/maven2/org/springframework/boot/spring-boot-starter-parent/4.0.8/spring-boot-starter-parent-4.0.8.pom)管理。

本模块采用 Boot 4.0.8 的 `spring-boot-starter-webmvc`、`spring-boot-starter-security` 和 `spring-boot-starter-test`。普通启动不设置用户名或密码属性，观察默认用户与随机生成密码。测试用例只覆盖测试上下文中的密码，以保证失败和成功请求可重复；该密码不是运行环境的默认密码。

## 环境确认与依赖核对

在本模块目录执行：

```bash
java -version
mvn -v
mvn clean verify
mvn -pl 21-04-001-hello-spring-security dependency:tree '-Dincludes=org.springframework:*,org.springframework.security:*,org.junit.jupiter:*,org.apache.tomcat.embed:*'
```

`java -version` 与 `mvn -v` 都应显示 Java 21；两者不一致时，先修正本机 Maven 使用的 JDK。依赖过滤参数加引号，以避免 shell 把星号当成文件匹配。

构建会从 Maven 仓库解析依赖，需要首次下载所需的网络访问。第一课运行只使用本机端口，不依赖数据库、Redis、Docker 或外部身份服务。8080 被占用时可在单课目录使用 `mvn spring-boot:run -Dspring-boot.run.arguments=--server.port=8081`，同时替换正文请求中的端口。

## 文档、源码与升级规则

参考说明使用 [Spring Security 7.0 文档](https://docs.spring.io/spring-security/reference/7.0/index.html)，该分支可能继续更新补丁版本；涉及具体实现时以 [Security 7.0.7标签](https://github.com/spring-projects/spring-security/tree/7.0.7)、[Boot v4.0.8标签](https://github.com/spring-projects/spring-boot/tree/v4.0.8)和本地解析的依赖为准。

在 IDE 中导入模块父 POM，并下载 Maven Sources。需要批量取得源码时，在本模块目录执行 `mvn -pl 21-04-001-hello-spring-security dependency:sources`。框架类必须打开依赖对应的 Sources，不能用另一版本网上的方法位置替代。

后续课程优先继承当前基线。升级时一起修改父 POM，核对实际依赖树，重新运行受影响章节的正常、拒绝与故障修复场景，并更新源码链接和验证记录。需要讲迁移差异时单独说明旧基线与新基线，不静默替换第一课已验证的版本。

本次验证环境为 macOS arm64；Java/Maven命令不依赖该架构。正文目录创建与复制命令采用 macOS/Linux shell，Windows 学习者可在 Git Bash 中执行；本次未单独验证 Windows、其他 JDK 或其他依赖版本。
