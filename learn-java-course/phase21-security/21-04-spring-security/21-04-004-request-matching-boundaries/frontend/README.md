# 第004课独立前端：路径与方法观察台

[课程正文](../README.md) · [验证记录](../01-验证记录.md) · [版本基线](../../01-版本基线.md)

前端是本课完整快照，使用原生HTML/JavaScript与Vite。新增近似路径、未知路径、OPTIONS操作；结果区与重试同时保留方法和路径。页面请求使用`Accept: application/json`、`credentials: omit`，不读取或保存密码；当前只观察匿名请求。带身份的403边界见正文终端实验。

## 启动与构建

先在本课后端目录执行`mvn spring-boot:run`，再在本目录执行：

```bash
npm ci
npm run dev
```

环境为Node22.15.0、npm10.9.2。打开`http://127.0.0.1:5173`；默认后端`http://127.0.0.1:8080`，前端`/api`代理去掉该前缀后转发。停止前课占用相同端口的服务。若后端用8081启动，本目录使用：

```bash
LESSON_BACKEND_URL=http://127.0.0.1:8081 npm run dev
```

`vite.config.js`设置`server.cors: false`，使同源OPTIONS继续到代理，避免Vite提前返回204。它仅改变开发服务器中间件，不能作为生产CORS配置。代理连接失败单独返回带来源标记的502，不改写正常后端状态。

本目录执行`npm run build`生成`dist/`。产物只包含静态前端；生产环境的API路由、同源部署与安全策略需另行配置，本课没有部署验证。

## 页面验收

公开GET为200，受保护、近似、未知路径的匿名GET为401，非法lang为400，普通OPTIONS公开路径为401。OPTIONS失败后重试仍应发OPTIONS，在Network和结果区同时检查。页面不携带Cookie，即使另一个标签页登录也保持本实验的匿名条件。

后端停止时显示代理502，恢复后可重试；浏览器离线时显示未取得完整响应。异常JSON格式保留原文和真实状态，不误判为网络断开。390像素视口可正常阅读、键盘触发操作且无横向溢出。

## 浏览器联合验证

本目录执行，Java与Maven版本也必须满足课程基线：

```bash
npx playwright install chromium
npm run test:e2e
```

需要指定Maven位置时可设置`MAVEN_CMD`为可执行文件路径，并设置正确的`JAVA_HOME`。准备脚本先对本课执行`mvn clean verify`，再在`.e2e-work/wrong-order/`构建只交换两条规则的隔离错序后端；正式源码保持正确顺序。

9项浏览器测试运行真实Java后端与Vite，验证错序/修复、认证及MVC响应、实际登录页面、后端停止恢复、离线恢复、窄屏键盘，以及近似/未知/OPTIONS及原方法重试。只有标明“响应格式异常”的一项注入5组响应，专门检查前端降级，不能据此证明后端授权。

测试自动使用空闲端口并清理进程；截图在`test-results/`，构建日志与无凭据业务计数在`.e2e-work/`。生成目录、node_modules、dist均不提交。完成版与正文跟写工程各通过25项后端和9项浏览器测试，详见课程验证记录。
