新增测试使用随机端口真实HTTP与Cookie容器，覆盖匿名/me的既有401契约，三用户表单登录后的重复身份读取，精确两个展示字段与no-store，显式Basic身份对照，伪造Cookie，服务端Session失效，伪造查询用户名，GET/HEAD/POST和近似路径边界，以及失败重登保留原身份。

加载延迟与畸形JSON是明确的测试注入，不把它们写成真实服务宕机。继承用例中，后端停机/代理502通过真实停止与恢复Java进程验证；登录成功后的CSRF刷新失败仅中断GET请求，登录POST真实执行。默认表单302对照工程保留本课/me，只恢复旧表单响应。

新增自动/me会产生正常的匿名401，因此继承的日志计数先等待启动身份查询结束，再取手动请求基线。未删除执行证据断言来掩盖额外请求。截图检查桌面与390px布局，密码框为空；trace关闭，不保存实际凭据到报告。

## 适用边界

本课只验证既定版本的Servlet内存会话与同源开发代理。没有验证分布式会话、生产CORS、跨源Cookie、业务角色授权、退出界面或跨标签页实时通知。页面反映最近一次后端查询结论，服务器或其他页面改变会话后，需要下一次查询或明确401才能更新展示。
