把页面结果与后端执行对应起来

  1. 看状态：200表示成功；401表示本次未通过认证；400参数错误需要修改输入。
  2. 看请求：在浏览器 Network 中找到 /api/public/info 或 /api/hello，检查状态与请求头。
  3. 看日志：401是否记录API_AUTHENTICATION_REQUIRED；400是否记录PUBLIC_INFO_HANDLER_REACHED及MVC_ERROR_HANDLED？
