# 21-04 Spring Security

[阶段21](../README.md) · [篇章级大纲](00-模块学习大纲.md) · [版本基线](01-版本基线.md) · [课程文档写作规范](../../01-课程文档写作规范.md)

本模块从一个受保护的 HTTP 接口开始，逐步建立认证、授权、会话与 Web 防护能力，再沿实际请求阅读核心源码，完成扩展、故障诊断、性能分析和业务应用。主线采用 Servlet / Spring MVC；响应式安全在具备 Reactor 和 WebFlux 基础后学习。

## 开始学习

需要能运行 Java 与 Maven 项目，理解依赖注入和 Spring MVC 请求映射，并能够辨认 HTTP 方法、请求头、响应状态、Cookie 与 Session。Servlet Filter 需要知道“可以在请求到达 Servlet 前处理或终止请求”；其框架桥接机制在第五篇展开。第一课不要求掌握 OAuth 2.0、JWT 或源码全貌。

完成后，应能实现并测试登录和权限规则，区分身份认证与资源访问权限，追踪认证及授权失败的处理路径，解释会话和令牌的适用边界，并根据证据完成安全扩展和故障定位。

## 学习顺序与课程进度

## 工程与运行

本目录的父 POM 继承 Spring Boot 4.0.8 的依赖和插件管理，聚合已完成课程；不挂入 Spring Core / IoC 的独立构建。使用 JDK 21、Maven 3.9.9，在本目录执行：

```bash
mvn clean verify
mvn -pl 21-04-001-hello-spring-security -am test
```

启动第一课需要切换到单课目录，避免在聚合父工程上执行启动目标：

```bash
cd 21-04-001-hello-spring-security
mvn spring-boot:run
```

默认仅监听本机 `127.0.0.1:8080`。运行时保留框架生成的默认用户密码；固定测试密码仅存在于测试配置中。第一课正文另给出独立跟写目录的建立方式，防止完成版测试干扰尚未加入安全依赖的步骤。
