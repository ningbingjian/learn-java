# 21-04 Spring Security

[阶段21](../README.md) · [逐课大纲](00-模块学习大纲.md) · [版本基线](01-版本基线.md) · [课程文档写作规范](../../01-课程文档写作规范.md)

本模块从一个受保护的 HTTP 接口开始，逐步建立认证、授权、会话与 Web 防护能力，再沿实际请求阅读核心源码，完成扩展、故障诊断、性能分析和业务应用。实践采用独立前端项目与Spring Security后端，按“页面操作、请求证据、后端机制、源码验证”递进。主线采用 Servlet / Spring MVC；响应式安全在具备 Reactor 和 WebFlux 基础后学习。

## 开始学习

需要能运行 Java 与 Maven 项目，理解依赖注入和 Spring MVC 请求映射，并能够辨认 HTTP 方法、请求头、响应状态、Cookie 与 Session。Servlet Filter 需要知道“可以在请求到达 Servlet 前处理或终止请求”；其框架桥接机制在第五篇展开。前端需要HTML与基础JavaScript；页面骨架直接提供，涉及请求、凭据、身份状态和错误处理的代码随课解释。第一课不要求掌握前端框架、OAuth 2.0、JWT 或源码全貌。

完成后，应能实现并测试登录和权限规则，区分身份认证与资源访问权限，追踪认证及授权失败的处理路径，解释会话和令牌的适用边界，并根据证据完成安全扩展和故障定位。

## 学习顺序与课程进度

先学基础使用、认证、授权和 Web 防护，得到可运行的应用；再进入核心源码、身份协议整合、扩展与工程治理。[逐课大纲](00-模块学习大纲.md)已按八篇拆分为89课：第001—080课为主线，第081—089课为9课选修。每课明确前置知识、学习目标、前端演进、后端机制和验收要求；目前第001—003课已实现，其余为编写计划。

## 工程与运行

本目录的父 POM 继承 Spring Boot 4.0.8 的依赖和插件管理，聚合已完成课程；不挂入 Spring Core / IoC 的独立构建。使用 JDK 21、Maven 3.9.9，在本目录执行：

```bash
mvn clean verify
mvn -pl 21-04-001-hello-spring-security -am test
```

启动第一课需要切换到单课目录，避免在聚合父工程上执行启动目标：

```bash
cd 21-04-001-hello-spring-security
mvn spring-boot:run
```

另开终端进入第一课的 `frontend/`：

```bash
npm ci
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`。完成版已启用安全认证，匿名按钮应显示401；从200开始的对照步骤见第一课正文。前端独立构建与浏览器验证命令见[前端项目说明](21-04-001-hello-spring-security/frontend/README.md)。

后端默认仅监听本机 `127.0.0.1:8080`。运行时保留框架生成的默认用户密码；固定测试密码仅存在于测试配置中。第一课正文另给出独立跟写目录的建立方式，防止完成版测试干扰尚未加入安全依赖的步骤。

第二课完整入口见[正文](21-04-002-explicit-security-filter-chain/README.md)与[前端说明](21-04-002-explicit-security-filter-chain/frontend/README.md)。启动前进入 `21-04-002-explicit-security-filter-chain`，后端和前端命令与第一课相同；默认端口相同，运行第二课前先停止占用端口的第一课进程。

第三课入口见[正文](21-04-003-api-authentication-errors/README.md)与[前端说明](21-04-003-api-authentication-errors/frontend/README.md)。进入 `21-04-003-api-authentication-errors`运行后端，另在其 `frontend/`运行前端；默认端口与前两课相同。
