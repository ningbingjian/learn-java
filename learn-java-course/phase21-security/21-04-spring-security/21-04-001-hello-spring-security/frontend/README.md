# 第001课独立前端：请求观察台

[第一课正文](../README.md) · [模块入口](../../README.md) · [版本基线](../../01-版本基线.md)

这个项目为第一课提供页面操作与请求观察入口。使用原生HTML、JavaScript和Vite；没有登录表单、身份存储或角色菜单。页面访问真实后端，显示实际HTTP状态和响应，不在前端伪造认证结果。

## 启动完成版

先在本课目录（本目录的上一级）用JDK21、Maven3.9.9执行 `mvn spring-boot:run`，默认监听 `127.0.0.1:8080`。另开终端在本目录执行：

```bash
node --version
npm --version
npm ci
npm run dev
```

基线为Node.js22.15.0、npm10.9.2、Vite8.2.2。打开 `http://127.0.0.1:5173`，点击“发送匿名请求”：完成版应显示401。要观察200，按[正文](../README.md)建立尚未引入安全依赖的跟写工程；不要通过放行所有请求替代这个对照。

页面请求同源的 `/api/hello`，Vite转发到后端 `/hello`。开发代理只在连接失败时生成带 `X-Lesson-Proxy-Error` 标记的502；后端401及其认证挑战按原样转发。浏览器没有直接跨源请求8080，本例不构成CORS整合测试。该代理仅用于本地课程开发。

如果后端改用8081，在本目录执行 `LESSON_BACKEND_URL=http://127.0.0.1:8081 npm run dev`。这是Vite进程的代理目标，不是页面可选择的访问地址；更改后需重启前端服务。5173被占用时会明确启动失败，可以使用 `npm run dev -- --port 5174` 并访问对应端口。

## 观察和故障恢复

| 条件 | 页面结果 | 应当检查 |
| --- | --- | --- |
| 无安全依赖的后端 | HTTP 200及业务JSON | Network和后端方法日志 |
| 当前受保护后端 | HTTP 401及真实响应内容 | 请求是否匿名、后端是否新增业务日志 |
| 前端保持运行，后端停止 | HTTP 502，来源标注为开发代理 | 后端启动与代理目标；重新启动后应恢复401 |
| 页面加载后浏览器切到Offline | 未取得完整响应，不推断身份结果 | 恢复网络后在同页重试，应恢复401 |

页面每次使用 `credentials: 'omit'`，没有Authorization头，也不保存用户信息。这个选择只为了第一课固定匿名条件；后续讲Cookie会话时必须重新设计凭据与CSRF交互。响应使用 `textContent` 显示，不执行HTML响应。

## 构建与验证

```bash
npm run build
npx playwright install chromium
npm run test:e2e
```

普通跟写只需安装npm依赖并运行开发服务，不需要测试浏览器。`build`生成 `dist/` 静态文件；该目录不带Java服务或Vite开发代理，正式部署需另行配置API入口。

`test:e2e`需要Java21及Maven3.9.9可执行文件。它先运行后端7项HTTP测试并打包，再在 `.e2e-work/` 内构建仅去掉安全依赖的对照工程，最后启动真实Java服务、Vite代理和Chromium，使用空闲端口完成5项浏览器测试。若Maven不在PATH，可通过 `MAVEN_CMD`指定可执行文件路径；`JAVA_HOME`用于明确JDK。测试结束自动关闭服务。

测试覆盖200、401与响应头透传、实际停止后端产生502及恢复、浏览器离线及恢复，以及390像素宽度和键盘操作。截图与失败追踪位于 `test-results/`，构建日志在 `.e2e-work/`，这些目录均不提交。验证范围及结果见[验证记录](../01-验证记录.md)。
