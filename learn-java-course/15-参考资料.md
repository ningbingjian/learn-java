# 15. 参考资料

[总导航](00-学习路线总导航.md) · [上一份：综合项目与架构案例](14-综合项目与架构案例.md)

以下资料用于概念核对和后续实现时的版本核对。

- **15.1** [Java 架构师完整学习路线：用户指定参考文章](https://blog.csdn.net/qq_45442483/article/details/148995442)：技术领域覆盖参考；当前大纲的阶段和编号已重新组织。
- **15.2** [Java 官方学习入口](https://dev.java/learn/)：Java 语言、标准库、虚拟线程与 JVM 工具。
- **15.3** [Java SE 支持路线](https://www.oracle.com/java/technologies/java-se-support-roadmap.html)：Java 版本和长期支持信息。
- **15.4** [Spring Boot 环境要求](https://docs.spring.io/spring-boot/system-requirements.html)：Java、构建工具和运行环境的兼容要求。
- **15.5** [Spring Cloud](https://spring.io/projects/spring-cloud)：配置、发现、路由、负载均衡和服务治理的项目入口。
- **15.6** [Spring Cloud LoadBalancer](https://docs.spring.io/spring-cloud-commons/reference/spring-cloud-commons/loadbalancer.html)：客户端负载均衡与实例选择。
- **15.7** [Spring Cloud OpenFeign](https://docs.spring.io/spring-cloud-openfeign/reference/index.html)：声明式 HTTP 客户端及官方演进建议。
- **15.8** [Spring HTTP Service Clients](https://spring.io/blog/2025/09/23/http-service-client-enhancements)：声明式 HTTP 服务客户端能力与集成。
- **15.9** [Spring Cloud Circuit Breaker 与 Resilience4j](https://docs.spring.io/spring-cloud-circuitbreaker/reference/spring-cloud-circuitbreaker-resilience4j.html)：熔断、隔离和配置。
- **15.10** [Spring Cloud Alibaba](https://sca.aliyun.com/en/)：Nacos、Sentinel、Seata、RocketMQ 等组件的集成入口。
- **15.11** [Spring Cloud Alibaba 官方仓库](https://github.com/alibaba/spring-cloud-alibaba)：版本、变更、样例和依赖信息。
- **15.12** [Nacos](https://nacos.io/en/)：服务发现和配置管理。
- **15.13** [Apache Dubbo 核心能力](https://dubbo.apache.org/en/overview/what/core-features/)：RPC、服务发现、流量治理与可观测性。
- **15.14** [Apache Dubbo 服务发现](https://dubbo.apache.org/en/overview/what/core-features/service-discovery/)：注册中心协作与服务发现机制。
- **15.15** [Apache Dubbo 应用级发现迁移](https://dubbo.apache.org/en/overview/mannual/java-sdk/reference-manual/upgrades-and-compatibility/migration-service-discovery/)：接口级与应用级发现的迁移。
- **15.16** [gRPC 官方介绍](https://grpc.io/docs/what-is-grpc/introduction/)：服务定义、客户端、服务端与 Protobuf。
- **15.17** [Google SRE Workbook](https://sre.google/workbook/table-of-contents/)：服务目标、观测、事故、容量与发布。
- **15.18** [OWASP ASVS](https://owasp.org/www-project-application-security-verification-standard/)：应用安全要求与验证范围。
- **15.19** [Spring AI](https://docs.spring.io/spring-ai/reference/index.html)：模型、RAG、工具、MCP、观测与评测。
