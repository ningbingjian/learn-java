# Java 从零基础到资深架构师：学习路线总导航

课程编写与维护请遵守 [01-课程文档写作规范](01-课程文档写作规范.md)。该规范适用于后续各专题的新增、续写和重构，统一理论深度、实操讲解及课程总结要求。

本版只确定阶段归属、阶段方向与目标，以及各模块的学习范围。模块内部的章节、知识点和源码阅读路径，后续逐个展开。

- 阶段对应一个领域或生态；模块对应具体技术、框架或独立学科。
- 软件模块均规划从零基础使用到深入原理、核心源码、扩展开发、故障分析与工程应用；下面的一句话只概述范围，不代替完整课程。
- 学科、协议与架构方法覆盖概念、推导、实现和验证。源码以具体实现为对象；商业平台只研究可获取的实现，例如 GitHub Actions 的开源 Runner。
- 阶段编号用于组织领域，并体现总体成长方向；实际学习按依赖分轮推进，不要求读完前一领域全部源码才能进入下一领域。设计模式、测试、安全等基础内容会前置使用。
- 源码学习随具体模块锁定版本，并补齐所需的 C/C++、Go、Erlang 等阅读基础。
- 不纳入 Java AI、知识服务或智能体。当前总纲按阶段与模块组织，具体课程后续逐步展开。

<a id="stage-01"></a>

**阶段01 计算机基础**

方向：建立理解程序、操作系统、网络与存储实现的基础。

目标：能够解释程序从代码到执行的过程，并用底层知识分析资源消耗与运行行为。

- **模块01-01 计算机组成原理**：从计算与硬件基础到处理器、存储层次及软硬件协作机制。
- **模块01-02 操作系统**：从进程与资源管理入门到内核机制、代表性实现与问题分析。
- **模块01-03 计算机网络**：从网络通信入门到协议机制、协议栈实现与通信故障分析。
- **模块01-04 数据结构**：从基础结构到复杂结构的实现、性能分析及框架源码中的应用。
- **模块01-05 算法**：从基本算法到复杂度分析、算法设计与工程问题求解。
- **模块01-06 编译原理**：从语言处理入门到编译流程、解释执行与代表性编译器实现。
- **模块01-07 C 语言**：从语法与内存基础到系统程序实现、调试及中间件源码阅读。
- **模块01-08 C++**：从语言基础到对象模型、资源管理及 HotSpot 等项目的源码阅读。

<a id="stage-02"></a>

**阶段02 Java 生态**

方向：系统学习 Java 语言、核心类库、并发与虚拟机。

目标：能够独立开发 Java 程序，并结合 JDK 与 JVM 实现解释行为、分析故障和优化性能。

- **模块02-01 Java SE**：从编程零基础到语言特性、核心 API、语言机制与相关 JDK 源码。
- **模块02-02 Java 集合框架**：从容器使用到数据结构、集合源码、性能特征与工程选型。
- **模块02-03 Java I/O**：从文件与流操作到缓冲、文件系统接口、JDK 实现与 I/O 性能分析。
- **模块02-04 Java 并发编程**：从线程入门到内存模型、JUC、虚拟线程、实现源码与并发诊断。
- **模块02-05 JVM**：从程序运行基础到虚拟机机制、HotSpot 核心源码、故障分析与调优。
- **模块02-06 Java 字节码与 Java Agent**：从字节码入门到类转换、Instrumentation 机制与探针实现。
- **模块02-07 ASM**：从字节码操作入门到框架实现源码、代码增强与调试实践。
- **模块02-08 Byte Buddy**：从运行时代码生成入门到增强机制、源码与 Agent 工程应用。
- **模块02-09 GraalVM Native Image**：从原生镜像构建到闭世界分析、核心实现与 Java 应用适配优化。

**阶段03 Linux 与系统工程**

方向：建立 Java 服务所需的操作环境、系统管理与自动化能力。

目标：能够独立部署和管理服务，分析主机、网络及系统资源问题。

- **模块03-01 Linux**：从命令与环境入门到系统管理、内核关键路径与服务运行分析。
- **模块03-02 Bash 与 Shell 编程**：从脚本入门到执行机制、可靠脚本编写与运维自动化。
- **模块03-03 systemd**：从服务管理入门到生命周期、资源约束、实现机制与异常恢复。
- **模块03-04 Linux 网络管理**：从网络配置到路由、防火墙与网络命名空间的机制及实现分析。
