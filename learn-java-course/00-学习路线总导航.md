## 0. 总体安排与导航

### 0.1 学习顺序与深度

- **0.1.1 基础与开发**：第 1—6 阶段建立 Java、工程、系统、数据库、Spring 与业务设计基础。
- **0.1.2 机制与分布式**：第 7—13 阶段进入并发、JVM、网络、中间件与微服务；同类组件先理解共性，再选择代表实现深入。
- **0.1.3 专题与生产**：第 14—17 阶段覆盖调度流程、数据服务、交付、安全与可靠性，结合业务需要安排专题顺序。
- **0.1.4 架构与方向**：第 18 阶段汇总系统设计与长期治理，第 19—20 阶段分别扩展平台架构和 Java AI 应用。
- **0.1.5 项目贯穿**：第 21 阶段的项目按对应知识阶段推进，随学习逐步升级；架构能力需要真实需求、运行反馈与长期演进经验。
- **0.1.6 深度标识**：标注“深入”的源码和性能专题适合在掌握基本用法后回访；每阶段说明要理解的机制和要处理的工程问题。
- **0.1.7 依赖衔接**：第 9—10 阶段先学单节点和使用语义，复制、协调与故障模型结合第 11 阶段复习；第 12 阶段涉及的事务与 Kubernetes 集成，分别在第 13、16 阶段继续展开。
- **0.1.8 版本选择**：实施时核对 Java、Spring Boot、Spring Cloud、Spring Cloud Alibaba、Dubbo 及中间件的兼容关系、支持状态和许可；具体版本以对应官方文档为准。
