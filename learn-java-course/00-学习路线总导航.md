# 00. Java 从零基础到资深架构师学习路线总导航

[返回仓库首页](../README.md)

本大纲包含 9 个主线阶段、4 个拓展方向和 1 个综合实践目录，共 157 章、1070 个三级条目、35 个四级细分条目。

第 01—09 阶段按主要知识依赖学习；第 10—13 阶段按工作方向深入；第 14 份文件汇集阶段项目和架构案例。每份阶段文件均含章节目录、总导航和前后文件链接。

文件以“序号-标题.md”命名，文件内沿用“阶段.章节.知识点.细分内容”编号。本次仅整理学习大纲，未制定每个单元的教学模板、课时或写作流程。

## 00.3 内容衔接

- 第 03 阶段建立 Spring 应用开发能力，第 04 阶段组织业务与模块，第 05 阶段深入 Java 运行机制。
- 第 06 阶段学习缓存、消息、一致性与分布式机制，第 07 阶段学习微服务框架及其集成。
- 第 08 阶段关注部署、观测、容量与恢复，第 09 阶段关注架构决策、迁移与团队落地。
- 第 10—13 阶段扩展网络组件、数据平台、云平台及 AI 应用能力。
- 综合项目与阶段对应关系见 [14-综合项目与架构案例](14-综合项目与架构案例.md)。

同类工具先选择一个实践对象，再对比其他实现；具体 JDK、Spring Boot、Spring Cloud、Alibaba 和 Dubbo 版本按官方兼容关系确定。
