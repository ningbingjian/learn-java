# 课程编写约束

适用范围：`learn-java-course/` 及其子目录内的课程大纲、教学文档与配套示例。

## 开始工作前

- 新增、续写或重构课程前，必须阅读并遵守 [01-课程文档写作规范.md](01-课程文档写作规范.md)。该文件是通用教学要求的统一来源。
- 结合所在阶段／模块的大纲、已有课程及适用的模块补充要求，确认任务范围、前置知识和当前核心机制。
- 用户在当前任务中的明确要求优先。按已授权范围完成工作，不因本文件增加额外确认环节，也不擅自扩大为全仓库重构。

## 编写与自查

- 核心小节采用“理论 → 实操中解释原理 → 小总结”；每课末必须有串起核心原理、结论、边界和应用方法的整课总结。
- 旧知识作必要回顾，本课核心知识详细解释。不能仅添加标题、堆贴完整代码或把自查问题当作整课总结。
- 保持跟写步骤、文件路径、运行入口和版本清晰；源码讲解需要说明关键数据、分支、执行时机与验证证据。
- 根据实际改动进行必要验证，如实报告结果；纯讲解修改可核对既有示例与导航一致性，不要求无目的地增加测试。
- 提交前依照写作规范第11节审阅内容，并检查受影响的链接和学习衔接。

## 规则维护

模块补充规则应引用统一规范并只描述新增要求。通用教学规则需要调整时维护统一规范，避免复制多份产生分歧。第001—008课可以提供写法示例，不能替代规范或成为所有模块必须照抄的模板。
